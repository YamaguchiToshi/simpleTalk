# コミュニケーションボード

50音表を使った音声フィードバック付きコミュニケーションボードです。

## 機能

- 50音表のボタン配置（右上に「あ」、縦に「い」「う」「え」「お」）
- 音声フィードバック（文字入力時と読み上げボタン）
- 濁点・半濁点・拗音促音の入力
- 停留クリック（Dwell Click）機能
  - アイトラッカーなどのポインティングデバイスに対応
  - ボタンヒステリシス（磁石効果）
  - 安定待機時間と速度閾値による誤動作防止

## 起動方法

### 方法1: Pythonサーバを使う（推奨）

```bash
cd /Users/toshi/src/simpleTalk
python3 server.py
```

ブラウザで `http://localhost:8000` にアクセスしてください。

### 方法2: 直接HTMLファイルを開く

`index.html` をブラウザにドラッグ&ドロップするか、ダブルクリックで開きます。

## 設定

右上の「⚙️ 設定」ボタンから以下を調整できます：

- **停留クリックを有効にする**: ON/OFF切り替え
- **停留時間**: ボタン上で停留してからクリックが発火するまでの時間（デフォルト: 700ms）
- **安定待機時間**: マウスが安定してから停留カウントを開始するまでの待ち時間（デフォルト: 150ms）
- **安定速度閾値**: この速度以下なら「安定している」とみなす閾値（デフォルト: 5px/s）
- **クールダウン時間**: クリック後、次のクリックまでの待ち時間（デフォルト: 200ms）

## 配色

- メインカラー: #4BA1D8（青）
- アクセントカラー: #173D64（濃紺）
- 背景: #FFFFFF（白）

## ブラウザ要件

- Web Speech API対応ブラウザ（Chrome、Edge、Safari等）
