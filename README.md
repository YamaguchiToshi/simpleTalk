# simpleTalk — コミュニケーションボード

50音表を使った音声フィードバック付きAAC（拡大代替コミュニケーション）ボードです。
視線入力デバイスなどのポインティングデバイスにも対応しています。

**デモ**: https://yamaguchitoshi.github.io/simpleTalk/

---

## 機能

### 文字入力
- **50音キーボード**: あ〜ん（わ行含む）を11列×5行のグリッドで表示
- **修飾モード**: ゛（濁点）・゜（半濁点）・ぁ（小文字）ボタンで入力可能な文字をその場で切り替え
- **長音符**: ー を直接入力するボタン
- **バックスペース**: 1文字削除

### 音声
- **文字ごとの読み上げ**: キーを押すたびに入力した文字を読み上げ
- **全文読み上げ**: chat_bubble ボタンでテキストエリアの内容をまとめて読み上げ
- **音声選択**: 端末にインストールされている日本語音声から選択可能（本体内蔵音声を表示）
- **Web Speech API** を使用（Chrome・Edge・Safari 等対応）

### 停留クリック（Dwell Click）
視線入力や頭部マウスなど、クリック操作が難しいデバイス向けの機能です。

| パラメータ | 説明 | デフォルト |
|-----------|------|----------|
| 停留時間 | ボタン上で停留してからクリックが発火するまでの時間 | 700ms |
| 安定待機時間 | マウスが安定してから停留カウントを開始するまでの待ち時間 | 150ms |
| 安定速度閾値 | この速度以下なら「安定している」とみなす | 5 px/s |
| クールダウン時間 | クリック後、次のクリックまでの待ち時間 | 200ms |

**ボタンヒステリシス（磁石効果）**: 停留中にボタン端付近にカーソルが差し掛かっても、ボタン幅の15%分の余裕を持たせることで意図しないキャンセルを防ぎます。

### その他
- **スクリーンロック防止**: Wake Lock API により操作中に画面がスリープしません
- **設定の永続化**: すべての設定は `localStorage` に保存され、次回起動時に復元されます

## 画面構成

```
┌─────────────────────────────────────────────────────┐
│  [delete]  テキストエリア（入力結果の表示）  [chat_bubble]  │
├─────────────────────────────────────────────────────┤
│                                                     │
│   ん  わ  ら  や  ま  は  な  た  さ  か  あ  ゛    │
│   を  （  り  （  み  ひ  に  ち  し  き  い  ゜    │
│   ん  （  る  ゆ  む  ふ  ぬ  つ  す  く  う  ぁ    │
│   （  （  れ  （  め  へ  ね  て  せ  け  え  ー    │
│   （  （  ろ  よ  も  ほ  の  と  そ  こ  お  ⌫    │
│                                                     │
└─────────────────────────────────────────────────────┐
                                      [settings] ←右下
```

- グリッドは右から左方向（あ行が右端）
- 空マスは非表示（や行・わ行の空欄など）
- 修飾モード（゛など）が選択されると、変換可能なボタンのみ有効化される

---

## 技術スタック

- **フロントエンド**: HTML / CSS / JavaScript（フレームワークなし）
- **音声**: [Web Speech API](https://developer.mozilla.org/ja/docs/Web/API/Web_Speech_API)
- **スクリーンロック防止**: [Screen Wake Lock API](https://developer.mozilla.org/ja/docs/Web/API/Screen_Wake_Lock_API)
- **アイコン**: [Material Icons](https://fonts.google.com/icons)（Google Fonts）
- **設定保存**: localStorage

## ファイル構成

```
simpleTalk/
├── index.html   # マークアップ・設定モーダル
├── style.css    # スタイル・レスポンシブ対応
├── script.js    # キーボード生成・音声・停留クリックロジック
└── server.py    # ローカル開発用 Python HTTP サーバ
```

---

## ローカルでの起動

```bash
python3 server.py
# → http://localhost:8000 でアクセス
```

または `index.html` をブラウザに直接ドラッグ＆ドロップしても動作します。
